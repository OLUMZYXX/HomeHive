# Assets

Place the following files here before running the app:

- `icon.png` — 1024×1024 app icon
- `splash.png` — 1284×2778 splash screen
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `favicon.png` — 32×32 web favicon

For development, you can use placeholder images. 
Recommended: Export these from the web's logo/branding assets in `client/src/assets/`.
